Latina In Tech è lieta di proporre, anche quest'anno, un evento estivo con contenuti di altissimo livello.

Come di consueto nei Lightning Talk, gli interventi avranno una durata di circa 30 minuti e saranno presentati nel seguente ordine.
Tre talk per esplorare potenzialità, rischi ed evoluzione del Web.

**HTTP QUERY — 10 anni dopo**  
Valentina Di Marco e Luca Visentin presentano il nuovo metodo HTTP QUERY, analizzandone casi d'uso, vantaggi e limiti.

**Capabilities Project: tra Web e Nativo 🐡**  
Davide Passafaro ci porta alla scoperta delle moderne Web API e del Capabilities Project, passando per le Progressive Web Apps e una demo pratica.

**Fingerprinting Web — Quando essere unici è un problema**  
Alessandro Miliucci mostra come il browser possa renderci riconoscibili anche senza cookie e quali contromisure possiamo adottare per proteggere la nostra privacy.
